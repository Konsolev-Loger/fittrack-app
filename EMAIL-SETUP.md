# Почта FIT Track

Почтовые функции временно отключены. Регистрация сразу открывает дневник, подтверждение
не требуется, ссылки восстановления скрыты, почтовые API возвращают 404. SMTP для запуска
не нужен. Для включения установи EMAIL_AUTH_ENABLED=true на сервере и
VITE_EMAIL_AUTH_ENABLED=true в клиенте, настрой SMTP и пересобери клиент.
Дальнейшая инструкция относится к включённому почтовому режиму.

## Локальная проверка без SMTP

По умолчанию сервер использует MAIL_MODE=preview. Письма наружу не отправляются.
После регистрации или запроса восстановления открой последний JSON-файл в
server/.mail-preview: поле text содержит ссылку для браузера.
Эти файлы содержат секретные ссылки и исключены из Git и Docker.

APP_URL по умолчанию http://127.0.0.1:5173. При другом адресе измени server/.env.
Повторное подтверждение: /check-email. Восстановление: /forgot-password.
Существующим аккаунтам тоже нужно подтвердить email при следующем входе.
Открытые сессии сохраняются до выхода или истечения. Дневники не изменяются.

## Настройки для публикации

Установи в секретах серверного хостинга, не в клиенте и не в Git:

```dotenv
APP_URL=https://your-site.example
MAIL_MODE=smtp
SMTP_HOST=smtp.provider.example
SMTP_PORT=587
SMTP_USER=your-smtp-user
SMTP_PASSWORD=your-smtp-password
MAIL_FROM=FIT Track <no-reply@your-domain.example>
```

APP_URL — точный адрес сайта без завершающего слэша. Обнови также FRONTEND_ORIGINS.
465 использует TLS сразу; 587 — обязательный STARTTLS.
Подтверди домен отправителя и настрой SPF/DKIM/DMARC по инструкции провайдера.
В production предпросмотр запрещён и обязательные настройки проверяются при запуске.
Реальная доставка пока не проверена: сервис ещё не подключён.
Документация: https://nodemailer.com/smtp

## Проверка после подключения

1. Зарегистрируй собственный тестовый email и проверь письмо, включая папку «Спам».
2. Открой ссылку, нажми «Подтвердить email», затем войди.
3. Запроси восстановление, открой письмо и сохрани новый пароль.
4. Проверь, что старый пароль и прежние сессии больше не работают.
5. Повторное использование ссылки должно выдавать ошибку.

Подтверждение действует 24 часа, восстановление — 30 минут. Повторная отправка —
через минуту. Ссылку потребляет только POST при подтверждении формы, не открытие страницы.
После сброса аннулируются все ссылки и сессии аккаунта. Сброс также подтверждает почту.
Ответы запросов писем одинаковы для неизвестных и существующих адресов.
Сбой доставки журналируется как "Account email delivery failed; check mail configuration."
без адресов и токенов. Исправь настройки и повтори запрос.
Для нескольких серверов потребуется общий rate-limit store; для массовой отправки — очередь.
